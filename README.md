# 누끼한방 다운로드

상품사진 배경 제거·쿠팡 규격 일괄 처리 프로그램 **누끼한방**의 설치 파일을 받는 곳이에요.

## 받기

오른쪽 **Releases**에서 가장 위(최신) 버전을 열고, 내 컴퓨터에 맞는 파일을 받으세요.

| 컴퓨터 | 파일 |
|---|---|
| Windows 11 | `Nukkihanbang-windows-버전.exe` |
| Apple 칩 맥 (M1 이후, macOS 14 이후) | `Nukkihanbang-mac-버전.dmg` |

- 체험판과 정품은 같은 파일이에요. 정품 키는 프로그램의 ⚙ 환경설정 → 정품 등록에 넣으면 돼요.
- 새 버전이 나오면 프로그램 위쪽에 **"새 버전 받기"** 버튼이 떠요. 받은 파일로 덮어 설치하면 정품 키와 설정은 그대로 남아요.
- 오류 수정과 성능 개선 업데이트는 무료예요. 큰 추가 기능은 나중에 따로 판매할 수 있어요.

## 처음 실행할 때

- **Windows:** "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 눌러 주세요.
- **맥:** 설치 파일 안의 「처음 실행하는 방법」을 따라 시스템 설정 → 개인정보 보호 및 보안 → [그래도 열기]를 눌러 주세요.

## 개인정보

누끼한방은 사진을 내 컴퓨터 안에서만 처리해요. 인터넷은 켜질 때 새 버전이 있는지 확인하는 데만 쓰고(버전 번호만 읽어요), 사진이나 개인 정보는 보내지 않아요.
